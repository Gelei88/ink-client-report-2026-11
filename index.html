整体架构

02

绑定笔

登录只认人，不认笔；绑定后再进入界面。右上角提供扫码绑笔。

03

老师端

标注 → 小笔 → 班级汇总 → 套题学生 → 资料室 → 笔迹中心 → 标注差异 → 智慧课堂。

04

学生端

我的套题 → 选择一页 → 笔迹中心 → 资料室；学生只看到自己的数据。

05

模块关系

同一份笔迹在标注、推理、资料与课堂之间流转；小笔 AI 横跨，数据中心是底座。

→

→

课堂实时 / 课后

老师 / 学生同一批数据，两个视角
