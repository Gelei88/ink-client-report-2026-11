19 号演示 Runbook

目标：用 20 分钟让学员价值先被看见，再讲架构。先演示 12a→12b 的真实推理，再补继续追问、老师端同一批证据；架构放最后。

01演示前 30 分钟：材料

老师侧

  • 选一套金标讲义/一页（当前金标）
  • 老师端标注好必勾/可选，确认能进标注中心
  • 打开班级汇总/套题学生，确认 32 人数据可见

学生侧

  • 学生 A/B 两支笔，提前绑定
  • 手动补符号/接地（识别实验不足，提前说明）
  • 确认 12a 有：312 条笔迹、5 处符号、作答、96 秒用时
  • 预跑 12b，保留截图/录屏兜底

环境

  • 本机 8099 / 18099 服务已起
  • 模型可用；不可用就走预跑结果
  • 两个浏览器窗口：学生 / 老师，避免现场切登录

兜底

  • 预跑 12a/12b 截图
  • 老师班级/对比截图
  • 不现场改数据、不把空态说成成功

0220 分钟演示顺序

时间做什么屏幕一句话
0–2先讲学员问题：普通解析只告诉答案，不告诉“我为什么错”封面/12a“学员做完题，平台能把他自己的过程还给他。”
2–4打开 12a：题目、我的选择、老师必勾、312 条笔迹都在；右栏还没跑12a“没有跑就没有结论；这里只显示缺什么。”
4–8点「问问小笔」，展示 12b：判断/依据/思路/对照/缺什么12b“不是答案 B，而是你哪一步把因此看成转折。”
8–11补一句「我为什么选 C」，再跑一次；打开小笔追问12b / 小笔“学生原话进入下一次上下文，报告会继续更新。”
11–15切老师端：班级汇总 → 套题学生 → 学生 A/B → 差异图 8/9/12“老师看到的是同一批证据的班级视图。”
15–18讲 Agent 与模块交互：标注→推理→资料→课堂；记忆/dreaming 离线图 2“内核+插件+记忆，不是更聪明的聊天框。”
18–20边界：符号手工、page_id/SSO/网关未接；下一步 P0/P1当前状态表“不把目标态当现状，先稳定推理效果。”

03两段学生路径

学生 A（主路径）：登录学生 → 我的套题 → S1言语 → 第 1 页 → 进入第 1 页·q1 → 12a → 问问小笔 → 12b → 补一句/重跑 → 小笔追问。
学生 B（对照）：同套题/同页，但笔迹/作答不同；重复 12a→12b，突出“同一道题，报告不一样”。
若第二支学生笔/第二账号未就绪：不伪造第二份报告。当前老师逐题页把「学生 A」写死，学生切换按钮无逻辑，点学生 G 仍显示 A；演示时改用老师端 32 人/差异视图 + 说明“第二份学生实跑待补”。

04现场操作路径

角色点击路径确认点
学生登录 → 绑定并进入 → 我的套题 → S1言语 → 第 1 页 → 进入第 1 页·q1看到 312 笔迹/5 符号/老师必勾
学生右栏「问问小笔」→ 等待 → 12b判断/依据/思路/缺什么出现
学生底部「补一句我为什么选 C」→ 再跑一次旧结论保留，新报告出现
老师切老师窗口 → 推理中心 → 班级汇总 → 套题学生 → 学生 A/B32 人/覆盖/差异可见
老师笔迹中心 → 对比/标注差异红学生/绿老师，命中/漏/错

05不要承诺的

  • 不承诺全自动符号识别/接地（演示为手工预标）
  • 不承诺在线 dreaming、自动画像已接入 12b 主链路
  • 不承诺多智能体/A2UI 全链路已实现
  • 不承诺自动发布讲评/改分/投屏
  • 不展示其他学生私有数据；投屏匿名

06演示后要定的三件事

1. 效果口径：12b 优先看判断/依据/缺什么，还是先看画像/对话？
2. 两支学生笔：谁来准备第二个学生账号/笔迹；是否需要我提前补符号？
3. 下一步 P0：推理 run 稳定、学生对话捕获、老师 HITL，先做哪一个？
