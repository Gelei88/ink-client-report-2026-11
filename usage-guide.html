客户端使用说明

本文按实际使用路径说明每个界面：入口、操作、看到什么、与前后模块怎么交接，以及 Agent 在该界面里的位置、输入和边界。

阅读顺序：启动 → 老师端 → 学生端 → Agent 与模块交互 → 记忆/dreaming → 当前边界。界面图见文末图号索引。
文档结构
01 启动（3 个界面）·02 老师端（10 个界面）·03 学生端（4 个界面）·04 模块 × Agent·05 记忆与 dreaming·06 当前边界

01启动

3 个界面：登录、绑定笔、拉取数据；这一段没有 Agent 生成，只建立身份、scope 和数据范围。

登录 · 封面

选身份并扫码登录

入口：启动客户端后的第一屏。

操作：在「老师/学生」中选一个身份，用阿里云/手机扫码或账号登录；登录后会先取当前用户、角色、班级和笔绑定状态。

结果：已绑定笔 → 首页；未绑定 → 绑定页；老师可稍后绑定进入只读首页。

Agent/模块：此处不启动 Agent。身份决定后面所有模块的 scope，学生只能看自己，老师只看本班。

身份scope二维码
图 3 · 绑定笔

输入 MAC/GUID 或扫码

入口：登录后无有效绑定时自动进入。

操作：输入笔身/包装上的 MAC 或 GUID；也可点右上角「扫码绑笔」；确认后进入拉取。

结果：写入本地设备/绑定关系；上游设备信息只读，不写回。

Agent/模块：无 Agent 主体；绑定只建立数据范围。未绑定的数据不分析、不进记忆。

MAC/GUID扫码入口只读上游
图 4 · 拉取数据

验证笔并拉取套题/页/笔迹

入口：绑定成功后自动进入。

操作：看「验证笔身份 → 拉取笔迹索引 → 准备推理数据」三步；中途可取消。

结果：完成后进入老师/学生首页；已拉取的索引不丢。

Agent/模块：拉取结果决定首页能看到哪些套题与页；此时 Agent 仍不生成结论，只等待后续按需调用。

长任务可取消数据范围

02老师端

10 个界面，按「标注 → 小笔 → 班级 → 套题 → 资料 → 笔迹 → 差异 → 课堂」排列。

图 5 · 标注数据

选套题与页

入口：侧栏「标注数据」。

操作：看套题卡（页数/符号数/已标进度），点套题或页卡进入标注中心。

结果：进入对应页的标注工作台。

Agent/模块：不调用生成式 Agent；它是老师标准的入口，后续推理只读引用已保存的必勾。

套题页进度
图 6 · 标注中心

画老师标准并保存

入口：标注数据 → 点套题/页。

操作：左侧选符号/接地文本，中间在讲义上画横线/圈/勾/叉，右侧选含义、原因、去向和必标/可选/易错/个人；完成后保存。

结果：形成可追溯的老师标准；可切页、看未保存状态。

Agent/模块：Agent 不替老师改标准；标注结果是推理/讲评的事实输入，不是模型推断。

老师标准必标/可选可追溯
图 7 · 小笔 AI

带上下文提问

入口：侧栏「小笔 AI」、⌘K、模块内「问问小笔」。

操作：看顶部上下文 chips（套题/页/题/角色/记忆条数），输入问题；Enter 发送，Shift+Enter 换行；可取消/打断。

结果：流式返回文字、推理折叠、工具卡、证据引用、UI 卡或审批卡；未知 UI 回退纯文本。

Agent/模块：chat 图 + TurnLoop，工具包括笔迹/题目/老师必勾/记忆；不能自动下结论或越权。

⌘KSSE证据
图 8 · 班级汇总

先看全班

入口：侧栏「推理中心」。

操作：看学生数/套题数/解析覆盖率/待关注；点套题进套题学生，点学生进逐题，点「查看全部」进学生列表。

结果：定位需要关注的套题和学生。

Agent/模块：teacher 图做班级聚合/错因聚类；只读本班 scope，不显示学生私有记忆；建议是候选，不自动发布。

班级聚合不评人
图 9 · 套题学生

一套题下的 32 张学生卡

入口：班级汇总 → 点套题。

操作：按覆盖/状态/错因筛选；点卡片进学生逐题；右侧看讲评包/提醒没跑的人；可导出。

结果：从套题层落到具体学生。

Agent/模块：交接班级汇总 → 套题学生 → 学生逐题；Agent 可解释差异，但不评人、不跳层。

套题学生卡提醒
图 10 · 资料室

套题、考点、讲评包

入口：侧栏「资料室」。

操作：看 AI 建议、套题资产、考点/错题、讲评包；点「新建讲评包」生成草稿。

结果：形成可复用的资料/讲评包草稿。

Agent/模块：content 图先取证据再列大纲/草稿；必须老师审核（采纳/编辑/删除/重生成），未审核不发布。

资料讲评包HITL
图 11 · 笔迹中心

学生 × 套题矩阵

入口：侧栏「笔迹数据中心」。

操作：看谁写了哪套/多少差异/谁未绑笔；点「对比」进差异页，点学生看详情。

结果：发现需要核对的差异。

Agent/模块：本身不生成结论；Agent 只按需解释某一页/某一差异，证据来自笔迹和标注。

矩阵差异未绑笔
图 12 · 标注差异

学生笔迹 vs 老师标准

入口：笔迹中心 → 对比/差异；或学生逐题。

操作：左学生（红）、右老师（绿）同坐标；切「对照明细/双画布/时间分析/助教面板」，切页/切学生；看命中/漏/错。

结果：核对老师标准有没有被学生命中。

Agent/模块：可问小笔解释这一页/这个差异；只读证据，不评价学生能力；教师复核是 HITL。

双画布命中/漏/错复核
图 13 · 课堂首页

开始上课前的检查

入口：侧栏「智慧实时课堂」。

操作：看下一节时间、笔就绪数、讲义标注页数、投屏状态；点「开始上课」。

结果：进入课堂；或查看历史课堂复盘。

Agent/模块：课前不生成课堂结论；副驾只在进入课堂后启动。

课前检查设备投屏
图 14 · 上课中

实时画布 + 学生状态

入口：课堂首页 → 开始上课。

操作：左工具切题、画笔/高亮；中间实时画布；右侧学生状态/AI 提示；老师「采纳」后才投屏。

结果：完成当前题/课堂；课后进入复盘。

Agent/模块：classroom 图消费事件；提示最多 1 主 + 2 候选；延迟 <2s；不自动投屏/发通知/改课件。

实时HITL 采纳匿名投屏

03学生端

4 个界面 + 逐题推理面板；学生只看自己的数据。

图 15 · 我的套题

从自己的套题进入

入口：学生登录后首页。

操作：看自己写过的套题、页数/题数/解析进度；点一套题进选页。

结果：进入该套题的页列表。

Agent/模块：不显示班级/他人/教师数据；小笔只能读自己的 context。

我的套题进度只看自己
图 16 · 选择一页

选页后进入逐题

入口：我的套题 → 点套题。

操作：看 7 页缩略、题数、已解析/未解析；点页卡进入逐题。

结果：进入该页的推理中心。

Agent/模块：页是标注/推理/笔迹的共同单位；逐题面板点「问问小笔」才运行，未跑不显示假结论。

页题数解析状态
图 16 下一层 · 逐题推理中心

未跑 → 运行 → 已解析

操作：未运行显示「这题还没有解析 + 问问小笔」；运行中显示步骤/取消；已解析显示判断、依据、考点覆盖、缺什么；可重跑/取消。

结果：只解释这一题；旧结论保留，不覆盖。

Agent/模块：reasoning 图；preflight → evidence tools → 结构化生成 → schema/证据校验；输出由后端写 run/report，Agent 不直接写业务表。

按需运行证据可取消/重跑
图 17 · 学生笔迹中心

自己的页与回放

入口：侧栏「笔迹数据中心」。

操作：按时间看自己的页/完成情况；回放；带当前页问小笔。

结果：回看自己的书写过程。

Agent/模块：只读自己的笔迹；不能看他人；Agent 可解释当前页，不读别的学生数据。

回放自己的页问小笔
图 18 · 学生资料室

只看发给自己的资料

入口：侧栏「资料室」。

操作：看自己的套题与讲评资产；点开看内容。

结果：获得老师发布/关联的资料。

Agent/模块：只读自己的资料；教师备课本/班级聚合不出现；内容发布由老师 HITL 完成。

资料讲评资产角色隔离

04模块 × Agent 交互

入口在客户端，编排在 Agent，能力在插件；客户端不直连 Agent/模型/数据库。

模块Agent 入口触发看什么/返回什么不能做
绑定笔无主体绑定完成只提示「小笔可用」不分析未绑定数据
标注数据/中心无生成入口保存老师标准推理后续读取 required_mark不替老师改标准
小笔 AI 全局侧栏/⌘K用户提问上下文 + 工具 + 记忆 + 证据不自动下结论/越权
学生逐题推理右栏 AgentPanel点「问问小笔」判断/依据/缺什么不自动跑、不评人
老师班级/套题右栏建议/差异进入班级/点学生聚合/错因/证据不读学生私有记忆
资料室AI 建议/新建包进入/生成草稿/来源/待补不自动发布
笔迹/差异「问小笔」选页/学生页级解释/差异证据不读他人、不评人
智慧课堂右栏 AI 提示实时/课后提示/举手摘要/复盘不自动投屏/发通知
记忆面板小笔 AI → 我的记忆查看/纠正/忘记记忆条目+证据+置信教师数据不进学生记忆

五条关键交互链

1. 登录 → 绑定 → 首页
客户端 → /me、/pen/* → 本地 PG；不经过 Agent。绑定成功才建立 data scope。
2. 标注 → 推理
标注中心保存老师标准 → 推理 run 读取 required_mark/题目/笔迹 → 结构化生成 → 后端 PG 写 run/report；Agent 不写业务表。
3. 推理 → 资料 → 课堂
已跑报告/班级聚合 → 讲评包草稿（老师 HITL）→ 课堂首页/上课中；课堂只消费已审核内容。
4. 课堂事件 → 副驾 → 投屏
事件流 → 提示候选 → 老师采纳 → 投屏；未采纳不投屏，投屏匿名。
5. 会话 → 记忆 → dreaming
事实事件只追加 → 离线 dreaming 输出独立 store → 审阅/合并；请求路径只读注入 ≤900 tok；学生可纠正/忘记。

05记忆、dreaming 与 Agent 边界

四层记忆

transcript 事实层只追加；notes 记忆层存 node/edge/candidate；wiki 是离线可重建的表示；注入层每轮 ≤900 tok，只读装配。检索先过滤 tenant/student/status，再按 confidence/recency/importance 排序，PPR 后置。

dreaming 不在请求路径

会话结束/每日批/手动触发；pending → running → completed/failed/canceled；输入 store + sessions → 输出 store；默认不合并。单次 9.6–18.8s，不放在线；不生成学生结论、不碰教师数据。

Agent 的硬边界

身份/scope/业务表/run 状态在 report-server；Agent 只做生成/证据/记忆/插件运行；客户端不直连 Agent/模型/数据库；教师动作 HITL；学生只看自己；不自动发布、不改分、不开放 shell。

06当前可用范围

按界面能走通的路径；没有的写清楚，不把目标态当现状。

可以走通：登录、绑定笔（含扫码）、标注数据/标注中心、小笔 AI、班级汇总、套题学生、资料室、笔迹中心、标注差异、课堂首页/上课中、学生端套题/选页/笔迹/资料。

当前未接：真实 SSO/组织同步、page_id 全量、symbol-service、content-pipeline、classroom-gateway :18121、生产 k8s/告警；这些在目标架构图里用虚线标为设计/未接。

使用顺序建议：先按「登录 → 绑定 → 标注 → 班级 → 套题 → 学生 → 课堂」走一遍；每一步确认角色、scope、证据和 HITL，再扩到真实数据。
